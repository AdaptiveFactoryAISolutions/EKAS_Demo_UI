# 20 Glossary

| Term | Meaning |
| --- | --- |
| Adapter Verified | An accepted test that this UI’s live adapter matches a real backend. Current value: NO |
| Case | The investigation opened for one gap, such as the feeder-jam plan miss |
| Context contract | The shared plant, line, machine, job, period, metric, and case |
| Demo mode | Synthetic fixtures, local rules, synthetic badge visible |
| Fail closed | Refuse in words and record nothing, rather than substitute another system |
| FPY | First-pass yield. Not a silent alias for OEE |
| Live Integration Verified | An accepted test against the live backend. Current value: NO |
| MES | The execution system of record. EKAS does not replace it |
| Modeled opportunity | A scenario of possible recovery. Not savings and not verified value |
| Observed loss | A governed actual-versus-plan or actual-versus-standard gap |
| Plant shortfall | The plant total below the approved plan. In the fixture, 150 good units |
| Line contribution | One line’s part of that shortfall. Line 03 is 138 |
| Policy 8 | The live referent rule. Older policies stay on older saved turns |
| RC3 | The frozen source `45568c5` plus the evidence added after the ZIP |
| Referent | The case or metric a pronoun such as “it” points at |
| Synthetic | Fixture data. Marked in the UI. Not a live plant |
| Verified financial value | A finance-accepted result. Distinct from observed loss and from modeled opportunity |
| Canonical entity | The governed EKAS id a source identifier may resolve to. Not a merge of similar names |
| EvidenceReference | Source system, source id, type, version, known-at, effectivity, and controlled status. Documented, not implemented on RC3 |
| Governed mapping | An authorized identity link. The only basis for combining cross-system evidence |
| Unresolved mapping | Two or more source records kept apart because no governed map links them |
