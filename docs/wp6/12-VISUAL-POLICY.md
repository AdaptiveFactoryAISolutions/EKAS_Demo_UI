# Clean-room visual and reference policy — EKAS DEMO RC1

The visual system accepted at `0d54c01` is presentation only. RC1 does not reopen it.

- Light is the default. Dark is optional and stored as a local appearance preference.
- Chat is the primary surface. Dashboards support the conversation.
- Icons are Lucide. Do not add proprietary ChatGPT or OpenAI artwork.
- Chrome stays neutral. Highcharts keeps its own analytical palette.
- Semantic color is for governed status only, not for decoration or series.
- The active navigation item is visible. Send looks like the primary action when it is enabled.
- Theme does not change a metric, a case, or a source.

Reference material from other products may inform spacing and hierarchy. It is not copied as a skin. EKAS should feel like one manufacturing expert, not a dashboard suite and not another vendor's chat product.
