# Acceptance cases and truthful limits

- Non-admin direct GET/write/test/enable/delete refused even when browser fictional role says Admin; unknown auth adapter denied. Cross-origin/null origin, wrong Host/port, unsupported ingress, missing/invalid session/CSRF and forged forwarding headers refused. Strict schemas/If-Match reject unknown fields/stale revision while preserving prior configuration.
- Dummy secret markers absent from every GET/response, localStorage/sessionStorage/IndexedDB, workspace persistence, URLs, exports, audit, logs and telemetry; no browser-to-OpenAI Authorization header. Raw field clears on submit, cancel, navigation, failed request and reload. Masked input is not claimed as extension protection or memory erasure.
- Save settings and Set credential make zero provider calls. Blank credential has no removal effect. Failed atomic replacement retains prior credential/reference and settings; successful key/model change invalidates current test/enable readiness. Explicit removal disables use but does not claim vendor revocation. Environment-managed credential is not overwritten through UI.
- Tiny synthetic inference Test states cost before explicit consent, reserves the same cumulative budget, handles duplicate/unknown outcomes without retry/spend duplication, and refuses expired/unreviewed/exhausted/unknown/in-flight states. A restricted key without models-list permission is not automatically rejected if allowed inference works. Show confirmed spend, in-flight reserves, unresolved usage and remaining allowance separately; unavailable real budget is unknown, not zero or a fresh USD20 grant.
- Disable stops new calls without refunding/canceling accounting for in-flight calls. Key rotation, restart, model changes and revised configuration never reset the original allowance. Previous tested result retains original time/revision and is labeled historical after changes.
- UI preserves existing visuals/navigation, labels and disabled helper text, focus/error/status semantics; no fake role grants operational access. Distinct mock configuration/ledger/secret marker is explicit. No screenshots or browser evidence while real credentials are present.
- Clearly disclose actual data categories sent for chat versus the fixed tiny synthetic test. store=false is not a Zero Data Retention promise. Provider monthly caps may lag and alerts do not stop requests; they supplement, not replace, EKAS accounting. Independent security hold remains; terminal fallback retained. Fresh source/build/compiled/fake HTTP/native review is bounded evidence, not live/Tom/security acceptance.
